# Ágora

**La plaza de tu salón.** Diapositivas sincronizadas para clase: el profe proyecta y los estudiantes siguen la clase desde sus computadores o celulares, responden preguntas, levantan la mano y hacen actividades.

Hecho en Saravena, Arauca, como alternativa gratuita a las lecciones de pago de otras plataformas.

## Qué hace

- Diapositivas importadas (PDF o imágenes) o creadas en el programa
- Preguntas de opción múltiple, verdadero o falso y abiertas
- Preguntas rápidas en plena clase, incluidas actividades HTML
- Ventana aparte para el proyector
- Puntero láser que ven todos
- Manos levantadas y participación anónima

## Cómo se usa

1. Abre la página y entra como **profe**.
2. Arma tu clase y toca **Empezar la clase**.
3. Los estudiantes abren la misma página, entran como **estudiante** y escriben el código.

Las diapositivas no se guardan en el navegador: usa **Guardar archivo** para conservarlas.
